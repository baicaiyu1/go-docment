# 静态资源与文件上传

> 一句话定位：静态目录用 `r.Static` / `r.StaticFS` / `r.StaticFile` 托管，上传用 `c.FormFile`；安全靠大小、类型、文件名、存储路径四道校验，`MaxMultipartMemory` 并不是请求体上限。

## 本篇目标

- 用 `r.Static`、`r.StaticFS`、`r.StaticFile` 托管静态资源，并区分它们与 `c.File` 的场景。
- 用 `c.FormFile`、`c.SaveUploadedFile` 完成上传，用 `MaxBytesReader` 设硬上限。
- 覆盖大小、扩展名、魔数、服务端文件名、路径穿越、临时文件清理，并抽象 `Storage` 接口对接 S3 / OSS。

## 一、三种静态托管方式

```go
// app/gateway/cmd/main.go（片段）
r.Static("/static", "./public")                      // /static/css/app.css → ./public/css/app.css
r.StaticFS("/assets", http.Dir("./public"))          // 自定义 http.FileSystem，可接 os.DirFS / embed
r.StaticFile("/favicon.ico", "./public/favicon.ico") // 单个固定文件
r.GET("/logo", func(c *gin.Context) { c.File("./public/logo.png") }) // 业务受控输出
```

- `r.StaticFS` 的参数是 `http.FileSystem`，传 `fs.FS` 必须包一层 `http.FS(fsys)`。
- 静态目录不要挂在 `/` 上，否则会抢走 API 路由；用 `/static`、`/assets` 独立前缀，生产也不要开目录列表。`c.File` 只用于路径服务端可控的业务文件。

## 二、上传的大小限制与临时文件

`r.MaxMultipartMemory` 只决定「多少字节放内存、超出写临时文件」，**不是请求体上限**。硬上限用 `http.MaxBytesReader`：

```go
// app/gateway/internal/middleware/limit.go
func BodyLimit(n int64) gin.HandlerFunc {
    return func(c *gin.Context) {
        c.Request.Body = http.MaxBytesReader(c.Writer, c.Request.Body, n)
        c.Next()
    }
}
```

超出上限时读取返回 `*http.MaxBytesError`，在 handler 里用 `errors.As` 映射成 413。临时文件由 `net/http` 在请求结束后自动 `RemoveAll`，因此保存必须在 handler 内完成，不能丢给 goroutine 稍后再读；手动调用过 `ParseMultipartForm` 时可显式 `defer c.Request.MultipartForm.RemoveAll()`。

## 三、完整上传 handler

```go
// app/gateway/internal/handler/upload.go
var allowedExt = map[string]bool{".jpg": true, ".jpeg": true, ".png": true, ".gif": true, ".webp": true}

func UploadHandler(st storage.Storage) gin.HandlerFunc {
    return func(c *gin.Context) {
        fh, err := c.FormFile("file") // 表单字段名，不是文件名
        if err != nil {
            var maxErr *http.MaxBytesError
            if errors.As(err, &maxErr) {
                c.JSON(http.StatusRequestEntityTooLarge, gin.H{"code": 40003, "message": "file too large"})
            } else {
                c.JSON(http.StatusBadRequest, gin.H{"code": 40001, "message": "file is required"})
            }
            return
        }
        ext := strings.ToLower(filepath.Ext(fh.Filename))
        if fh.Size <= 0 || fh.Size > 5<<20 || !allowedExt[ext] {
            c.JSON(http.StatusBadRequest, gin.H{"code": 40002, "message": "invalid size or type"})
            return
        }
        if err := checkMagic(fh); err != nil {
            c.JSON(http.StatusBadRequest, gin.H{"code": 40004, "message": "content mismatch"})
            return
        }
        f, err := fh.Open()
        if err != nil {
            c.JSON(http.StatusInternalServerError, gin.H{"code": 50001, "message": "internal error"})
            return
        }
        defer f.Close()
        // 文件名由服务端生成，绝不用 fh.Filename 拼路径
        key := fmt.Sprintf("%s/%s%s", time.Now().Format("20060102"), uuid.NewString(), ext)
        if err := st.Save(c.Request.Context(), key, f, fh.Size, mime.TypeByExtension(ext)); err != nil {
            c.JSON(http.StatusInternalServerError, gin.H{"code": 50001, "message": "save failed"})
            return
        }
        c.JSON(http.StatusOK, gin.H{"code": 0, "data": gin.H{"key": key, "size": fh.Size}})
    }
}
```

`c.SaveUploadedFile(fh, dst)` 是本地磁盘的简化版：会创建目标文件并复制，但不建父目录、不做校验，只适合原型。

## 四、安全校验与路径穿越

```go
// pkg/storage/path.go
func safeJoin(base, key string) (string, error) {
    p := filepath.Join(base, filepath.FromSlash(path.Clean("/"+key))) // 以 / 为根清洗，消掉 ..
    rel, err := filepath.Rel(base, p)
    if err != nil || strings.HasPrefix(rel, "..") {
        return "", fmt.Errorf("invalid key %q", key)
    }
    return p, nil
}
// app/gateway/internal/handler/validate.go
func checkMagic(fh *multipart.FileHeader) error {
    f, err := fh.Open()
    if err != nil {
        return err
    }
    defer f.Close()
    head := make([]byte, 512)
    n, _ := io.ReadFull(f, head)
    if ct := http.DetectContentType(head[:n]); !strings.HasPrefix(ct, "image/") {
        return fmt.Errorf("unexpected content type: %s", ct)
    }
    return nil
}
```

## 五、对象存储抽象

本地磁盘只用于开发，生产应放 S3 / OSS 并交给 CDN。用接口隔离，本地实现由 `storage.NewLocal(dir)` 返回（`safeJoin` + `os.OpenFile(O_EXCL)` + `io.Copy`），业务 handler 不感知实现：

```go
// pkg/storage/storage.go
type Storage interface {
    Save(ctx context.Context, key string, r io.Reader, size int64, contentType string) error
    Open(ctx context.Context, key string) (io.ReadCloser, error)
    URL(ctx context.Context, key string, ttl time.Duration) (string, error) // 预签名地址
}
```

- S3 用 `aws-sdk-go-v2` 的 `PutObject` / `GetObject` / `PresignGetObject`，OSS 用 `aliyun-oss-go-sdk`；有 `URL` 就能把下载交给 CDN，网关只发短期签名地址。

## 六、下载的鉴权与限速

下载必须过鉴权中间件（如 `middleware.AuthRequired`），不能把上传目录直接静态暴露；大文件要限速，否则单连接就能打满出口带宽：

```go
// app/gateway/internal/handler/download.go
func DownloadHandler(st storage.Storage) gin.HandlerFunc {
    return func(c *gin.Context) {
        rc, err := st.Open(c.Request.Context(), strings.TrimPrefix(c.Param("key"), "/"))
        if err != nil {
            c.JSON(http.StatusNotFound, gin.H{"code": 40401, "message": "file not found"})
            return
        }
        defer rc.Close()
        c.Header("Content-Disposition", "attachment") // 强制下载，避免 HTML/SVG 内联 XSS
        c.Header("X-Content-Type-Options", "nosniff")
        limiter := rate.NewLimiter(rate.Limit(2<<20), 4<<20) // 2MB/s，突发 4MB
        buf := make([]byte, 32<<10)
        for {
            n, rerr := rc.Read(buf)
            if n > 0 {
                if limiter.WaitN(c.Request.Context(), n) != nil {
                    return
                }
                if _, err := c.Writer.Write(buf[:n]); err != nil {
                    return
                }
            }
            if rerr != nil {
                return
            }
        }
    }
}
```

## 完整示例

`app/gateway/cmd/main.go`（handler 与 storage 实现见上文）：

```go
package main

import (
    "github.com/gin-gonic/gin"
    "mall-lite/app/gateway/internal/handler"
    "mall-lite/app/gateway/internal/middleware"
    "mall-lite/pkg/storage"
)

func main() {
    r := gin.New()
    r.Use(gin.Logger(), gin.Recovery(), middleware.BodyLimit(10<<20))
    r.MaxMultipartMemory = 8 << 20
    st := storage.NewLocal("./uploads")
    r.Static("/static", "./public")
    r.POST("/api/v1/files", handler.UploadHandler(st))
    r.GET("/api/v1/files/*key", middleware.AuthRequired(), handler.DownloadHandler(st))
    _ = r.Run("127.0.0.1:8080")
}
```

## 常见坑

1. **把 `MaxMultipartMemory` 当请求上限**：它只决定内存与临时文件的分界；硬限制用 `MaxBytesReader`。
2. **用 `fh.Filename` 拼存储路径**：`../../etc/passwd` 可穿越；文件名必须服务端生成。
3. **只校验后缀**：改名的脚本照样通过；必须读魔数校验内容。
4. **先返回响应再保存文件，或 `SaveUploadedFile` 目录不存在**：临时文件已被清理、目标目录不会自动创建；保存必须在 handler 内完成并提前 `MkdirAll`。
5. **上传目录放在静态目录下**：文件可被直接访问甚至执行；存储与托管分离。
6. **内联返回用户上传的 HTML/SVG**：存储型 XSS；统一 `attachment` + `nosniff`。

## 小结

- 静态资源用 `r.Static` / `r.StaticFS` / `r.StaticFile`，业务文件用 `c.File`，路径必须服务端可控。
- 上传硬上限是 `MaxBytesReader`，`MaxMultipartMemory` 只管内存与临时文件的分界；四道校验是大小、扩展名、魔数、服务端文件名。
- 生产用 `Storage` 接口接 S3 / OSS，预签名 URL 或受控下载接口输出，并加鉴权与限速。

## 一、Go 是什么，为什么值得学

Go（Golang）是 Google 2009 年开源的静态编译语言，五个特点决定了它适合服务端：

1. **单个静态二进制**：`go build` 产出一个文件，拷到服务器就能跑。
2. **语法极小**：25 个关键字，没有继承。
3. **原生并发**：`goroutine` + `channel` 让高并发成为语言级能力。
4. **自带 GC 与内存安全**：不用手动释放，也不易越界。
5. **标准库强**：`net/http`、`encoding/json`、`context` 直接可用，Gin 建立在其上。

```go
func main() {

```

## 三、package main、func main 与 import

- 每个 `.go` 文件第一行非注释代码必须是 `package 包名`，同一目录下所有文件的包名必须一致
- **可执行程序必须使用 `package main`**，否则 `go run` 会报 `is a program, not an importable package`
- `main` 函数是程序入口，**无参数、无返回值**；只有 `package main` 里的 `main` 会被执行
- 程序从 `main` 开始，`main` 返回即进程退出

导入多个包时用括号分组（`gofmt` 会自动对齐），三种特殊写法：

```go
import (
	_ "net/http/pprof" // 只执行包的 init，不使用其导出名
	m "math"           // 起别名，之后用 m.Pi
	. "fmt"            // 点导入，直接调用 Println（不推荐）
)
```

**包名与目录的关系**：`import "net/http"` 对应 `GOROOT/src/net/http` 目录，包名是 `http`。你自己写的包，目录名通常等于包名，例如 `internal/user` 下写 `package user`。

未使用的 import 会**直接编译失败**，这不是警告，是错误——Go 用这种方式强制你保持依赖干净。

## 四、go run 与 go build

```powershell
go run .
go build -o hello.exe .
.\hello.exe
```

```bash
go run .
go build -o hello .
./hello
```

| 维度 | `go run` | `go build` |
| --- | --- | --- |
| 产物 | 临时目录，退出即删 | 当前目录的可执行文件 |
| 速度 | 每次重新编译（有缓存） | 编译一次，反复运行 |
| 适用 | 开发期验证 | 交付、部署、压测 |

**`go run` 也是先编译再执行**，Go 没有解释器。

## 五、fmt 格式化输出

四个常用函数：`fmt.Print`（原样输出）、`fmt.Println`（加空格与换行）、`fmt.Printf`（按格式串）、`fmt.Sprintf`（返回字符串不输出）。

| 占位符 | 含义 | 示例输出 |
| --- | --- | --- |
| `%v` | 默认格式 | `{1 alice}` |
| `%+v` | 带字段名 | `{ID:1 Name:alice}` |
| `%#v` | Go 语法表示 | `main.User{ID:1, Name:"alice"}` |
| `%T` | 类型 | `main.User` |
| `%d` / `%s` | 整数 / 字符串 | `42` / `gin` |
| `%q` | 带引号字符串 | `"gin"` |
| `%t` | 布尔 | `true` |
| `%.2f` | 保留两位小数 | `3.14` |

模拟一条请求日志：

```go
package main

import (
	"fmt"
	"time"
)

type RequestLog struct {
	Method string
	Path   string
	Status int
	Cost   time.Duration
}

func main() {
	log := RequestLog{Method: "GET", Path: "/api/users", Status: 200, Cost: 12 * time.Millisecond}

	fmt.Printf("[%s] %s %s %d %s\n",
		time.Now().Format("2006-01-02 15:04:05"),
		log.Method, log.Path, log.Status, log.Cost,
	)
	fmt.Printf("带字段名：%+v\n", log)
	fmt.Printf("类型是：%T\n", log)
}
```

输出类似 `[2026-11-23 10:00:00] GET /api/users 200 12ms`。注意时间格式 `"2006-01-02 15:04:05"`——Go 用**固定参考时间**而不是 `yyyy-MM-dd`，记住 `2006 01 02 15 04 05` 即可。

## 六、命名与注释约定

```go
// Hello 返回一句问候。
// 以函数名开头的注释会被 godoc 提取，导出标识符建议都写。
func Hello(name string) string {
	return "hello, " + name
}
```

- 导出（其他包可见）首字母大写 `UserService`，不导出小写 `userService`
- 包名全小写、简短、无下划线：`user`、`httpx`
- 变量名用驼峰：`userID` 而不是 `user_id`；缩写词保持一致大小写：`URL`、`ID`、`HTTPClient`

## 七、用命令行参数写一个小工具

```go
package main

import (
	"fmt"
	"os"
)

func main() {
	if len(os.Args) != 2 {
		fmt.Fprintf(os.Stderr, "用法: %s <port>\n", os.Args[0])
		os.Exit(1)
	}
	port := os.Args[1]
	fmt.Printf("服务将监听 0.0.0.0:%s\n", port)
	fmt.Printf("健康检查地址: http://127.0.0.1:%s/healthz\n", port)
}
```

```text
go run . 8080
```

`os.Args[0]` 是程序名，`os.Args[1:]` 才是用户参数。`fmt.Fprintf(os.Stderr, ...)` 把错误写到标准错误流，这是命令行工具的标准做法。

## 常见坑

1. **忘记 `package main`**：写成 `package hello` 后 `go run` 会报找不到 main 包。
2. **import 了不用**：Go 视为编译错误，不是警告；正确做法是删掉。
3. **以为 `go run` 是解释执行**：它每次都编译，改代码后无需额外「重启解释器」，但也没有热更新。
4. **时间格式写成 `yyyy-MM-dd`**：Go 必须用参考时间 `2006-01-02`，写错会原样输出字母。
5. **多个 `main` 函数放在同一目录**：同一包内不允许重复定义 `main`，每个可执行程序要独立目录。

## 一、变量声明：三种写法

```go
package main

import "fmt"

func main() {
	var host string = "127.0.0.1" // 1. 标准写法
	var port = 8080               // 2. 类型推断
	env := "dev"                  // 3. 短声明，只能在函数内

	var (
		serviceName = "user-service" // 批量声明，配置代码常见
		debugMode   = false
	)

	fmt.Println(host, port, env, serviceName, debugMode)
}
```

选择建议：需要显式类型（如 `int64`、`time.Duration`）用 `var n int64 = 0`；函数内能推断用 `n := 0`；包级变量用 `var DefaultPort = 8080`。

**为什么 Go 推荐短声明？** 它让变量的类型由右值决定，减少重复。但短声明有严格限制：只能在函数内使用，且**左边至少有一个新变量**。

```go
a, b := 1, 2
a, c := 3, 4 // 合法：c 是新变量，a 被重新赋值
// a, b := 5, 6 // 非法：没有新变量，编译报错
```

## 二、零值：Go 的默认初始化

声明但未赋值的变量会被自动赋予零值，不会出现未定义内存：

| 类型 | 零值 |
| --- | --- |
| 整数 | `0` |
| 浮点 | `0` |
| `bool` | `false` |
| `string` | `""`（空串，不是 nil） |
| 指针、`interface`、`map`、`slice`、`chan`、`func` | `nil` |
| `struct` | 每个字段各自取零值 |

```go
var (
	count int
	name  string
	ok    bool
	user  *User
)

fmt.Printf("%d %q %t %v\n", count, name, ok, user) // 0 "" false <nil>
```

零值的设计意义：**让「零值可用」成为库的设计目标**。`sync.Mutex`、`bytes.Buffer` 零值即可用；你写结构体时也应尽量让零值有意义，这样调用方不用记「必须先 New」。

注意：`nil` 的 map 不能写入、`nil` 的 slice 可以 `append`，这是 [06-切片-map-字符串](06-切片-map-字符串.md) 的重点。

## 三、常量与 iota

常量在编译期确定，不能被修改：

```go
const (
	ServiceName = "user-service"
	MaxRetry    = 3
)
```

`iota` 是常量声明块中的行号计数器，从 0 开始，每行递增 1：

```go
type LogLevel int

const (
	LevelDebug LogLevel = iota // 0
	LevelInfo                  // 1
	LevelWarn                  // 2
	LevelError                 // 3
)
```

常见技巧是配合位移表示容量：

```go
const (
	_  = iota             // 跳过 0
	KB = 1 << (10 * iota) // 1 << 10 = 1024
	MB                    // 1 << 20
	GB                    // 1 << 30
)
```

插入一行，后面的值自动调整，而且值是编译期常量，没有运行时开销。

**无类型常量**是 Go 的便利特性：`const Answer = 42` 可以直接赋给 `int64` 或 `float64`；写成 `const Answer int = 42` 就只能赋给 `int`。所以**默认不要给常量加类型**。

## 四、基本类型与类型转换

| 类别 | 类型 | 说明 |
| --- | --- | --- |
| 布尔 | `bool` | 只有 `true` / `false`，不能与 0/1 互转 |
| 字符串 | `string` | 不可变的 UTF-8 字节序列 |
| 有符号整数 | `int`、`int8/16/32/64` | `int` 在 64 位平台是 64 位 |
| 无符号整数 | `uint`、`uint8/16/32/64` | `uint8` 即 `byte` |
| 浮点 | `float32`、`float64` | 默认用 `float64` |
| 字符 | `byte`、`rune` | `byte` 是字节，`rune` 是 Unicode 码点 |

选型建议：计数与循环用 `int`；协议与序列化用明确位宽；金额**不要用 float**，用 `int64` 存「分」；时间间隔用 `time.Duration`。

Go 没有隐式类型转换，`int` 和 `int64` 是两个不同的类型：

```go
var a int = 10
var b int64 = int64(a) // 必须显式转
var c float64 = float64(b)

var big int32 = 300
var small int8 = int8(big) // 窄化截断：结果是 44
```

字符串与数字之间不能直接转，要用 `strconv`：

```go
n, err := strconv.Atoi("8080") // string -> int
if err != nil {
	fmt.Println("非法端口:", err)
}
s := strconv.Itoa(8080) // int -> string
```

注意 `string(65)` 得到的是字符 `"A"`，不是 `"65"`。要数字转字符串用 `strconv.Itoa`。

## 五、字符串、byte 与 rune

Go 的 `string` 是**只读的字节序列**，通常按 UTF-8 编码存储。两个必须记住的事实：`len(s)` 返回**字节数**；`s[i]` 取到的是 `byte`。

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	s := "Go语言"

	fmt.Println(len(s))                    // 8：G、o 各 1 字节，语、言 各 3 字节
	fmt.Println(utf8.RuneCountInString(s)) // 4：4 个字符

	fmt.Printf("%c\n", s[0]) // G
	// fmt.Printf("%c\n", s[2]) // 取到「语」的第一个字节，输出乱码

	for i, r := range s {
		fmt.Printf("字节位置=%d 字符=%c 码点=%U\n", i, r, r)
	}
}
```

`for range` 遍历字符串时会自动按 UTF-8 解码，`r` 是 `rune`，`i` 是字节偏移（不是第几个字符），这是处理中文最安全的方式。

字符串不可变，每次拼接都会产生新字符串。循环内大量拼接应改用 `strings.Builder`，见 [06-切片-map-字符串](06-切片-map-字符串.md)。

## 六、实战：服务配置片段

```go
const defaultPort = 8080

type Config struct {
	Host    string
	Port    int
	Timeout time.Duration
	Debug   bool
}

func loadConfig() (Config, error) {
	port := defaultPort
	if raw := os.Getenv("APP_PORT"); raw != "" {
		p, err := strconv.Atoi(raw)
		if err != nil {
			return Config{}, fmt.Errorf("APP_PORT 不是合法整数: %w", err)
		}
		port = p
	}
	debug, _ := strconv.ParseBool(os.Getenv("APP_DEBUG"))
	return Config{Host: "0.0.0.0", Port: port, Timeout: 5 * time.Second, Debug: debug}, nil
}

func main() {
	cfg, err := loadConfig()
	if err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}
	fmt.Printf("监听 %s:%d，超时 %s，debug=%t\n", cfg.Host, cfg.Port, cfg.Timeout, cfg.Debug)
}
```

这段代码具备企业级配置加载的雏形：常量给默认值、环境变量覆盖、错误包装返回。后面的 Hertz 项目会用到同样的模式。

## 常见坑

1. **`string(65)` 得到 `"A"` 而不是 `"65"`**：数字转字符串请用 `strconv.Itoa`。
2. **用 `len` 判断中文长度**：得到的是字节数，需要字符数用 `utf8.RuneCountInString`。
3. **`nil` map 直接赋值**：`var m map[string]int; m["a"]=1` 会 panic，必须先 `make`。
4. **整数溢出静默截断**：`int8(300)` 不报错，得到 44；转换前先确认范围。
5. **短声明重复定义**：`a := 1; a := 2` 编译报错，第二次要用 `=`；包级变量只能用 `var`。
6. **浮点比较用 `==`**：`0.1+0.2 != 0.3`，涉及金额务必用整数或 decimal。

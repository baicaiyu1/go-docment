## 一、if：支持初始化语句

Go 的 `if` 可以在条件前写一条初始化语句，用分号隔开：

```go
if n, err := strconv.Atoi(raw); err == nil {
	fmt.Println("端口是", n)
} else {
	fmt.Println("非法端口:", err)
}
```

`n` 和 `err` 的作用域被限制在 `if/else` 块内，不会污染外层。Web 处理器里常见同样的形态：`if user, err := repo.FindByID(ctx, id); err != nil { ... }`。

注意：条件必须是 `bool`，Go 不允许 `if 1 {}`；左大括号 `{` 必须与 `if` 同行；`else` 必须紧跟 `}`，这是语法要求而不是风格。

## 二、for：唯一的循环关键字

Go 没有 `while`，所有循环都用 `for`：

```go
for i := 0; i < 3; i++ { // 经典三段式
	fmt.Println("i =", i)
}

n := 3
for n > 0 { // 只写条件，等价于 while
	fmt.Println("n =", n)
	n--
}

count := 0
for { // 无限循环
	count++
	if count >= 2 {
		break
	}
}
```

`for range` 用于遍历数组、切片、字符串、map、channel：

```go
m := map[string]int{"a": 1, "b": 2}
for k, v := range m {
	fmt.Println(k, v) // map 遍历顺序是随机的
}

for _, p := range []int{8080, 8081} { // 不需要下标时用 _
	fmt.Println(p)
}
```

两个关键细节：

1. **`range` 返回的是副本**：`for _, u := range users` 里的 `u` 是元素副本，修改它不影响切片；要改元素请用下标 `users[i].Name = ...`
2. **Go 1.22 起循环变量每轮独立**：闭包捕获 `i` 不再共享同一个变量，下面这段安全输出 `012`

```go
var funcs []func()
for i := 0; i < 3; i++ {
	funcs = append(funcs, func() { fmt.Print(i) })
}
for _, f := range funcs {
	f()
}
```

老文章里的 `i := i` 是 Go 1.22 之前的写法，读旧代码时知道来由即可。

## 三、switch：默认不穿透

```go
status := 404
switch status {
case 200, 201:
	fmt.Println("成功")
case 400, 404:
	fmt.Println("客户端错误")
default:
	fmt.Println("其他")
}
```

与 C/Java 的区别：每个 `case` 结束自动 `break`；需要穿透时显式写 `fallthrough`（极少用）；`case` 可以写多个值。

无表达式的 `switch` 相当于 `if-else if` 链，还可带初始化语句：

```go
switch n, err := strconv.Atoi(raw); {
case err != nil:
	fmt.Println("解析失败")
case n > 65535:
	fmt.Println("端口越界")
default:
	fmt.Println("端口", n)
}
```

## 四、函数：多返回值是常态

Go 的函数可以返回多个值，最典型的是「结果 + 错误」：

```go
func divide(a, b int) (int, error) {
	if b == 0 {
		return 0, fmt.Errorf("除数不能为 0")
	}
	return a / b, nil
}
```

调用方必须显式处理：`result, err := divide(10, 2)` 后用 `if err != nil` 判断，错误处理见 [05-错误处理与panic-recover](05-错误处理与panic-recover.md)。

命名返回值可在签名里给出名字，配合 `defer` 修改返回值，但**不要滥用**，否则读者要追踪每个 `return` 实际返回了什么：

```go
func parsePort(raw string) (port int, err error) {
	port, err = strconv.Atoi(raw)
	if err != nil {
		return 0, fmt.Errorf("端口 %q 非法: %w", raw, err)
	}
	if port < 1 || port > 65535 {
		return 0, fmt.Errorf("端口 %d 越界", port)
	}
	return port, nil
}
```

可变参数：`func sum(nums ...int) int` 内部 `nums` 是 `[]int`；传切片时要用 `...` 展开：`sum([]int{4, 5}...)`。

## 五、函数是一等公民与闭包

函数可以赋给变量、作为参数、作为返回值：

```go
type Handler func(req string) string

func logging(next Handler) Handler {
	return func(req string) string {
		fmt.Println("-> 收到请求:", req)
		resp := next(req)
		fmt.Println("<- 返回响应:", resp)
		return resp
	}
}

func main() {
	hello := func(req string) string { return "hello, " + req }
	fmt.Println(logging(hello)("hertz"))
}
```

这就是「中间件」的雏形：**接收一个 Handler，返回一个新的 Handler**。Hertz 的中间件签名虽然带 `context.Context`，思想完全一致。

闭包捕获的是**变量本身**而不是值的快照，所以多次调用会累积计数；循环里捕获循环变量则依赖 Go 1.22+ 的每轮独立语义。

## 六、defer：延迟到函数返回时执行

`defer` 常用于资源释放：

```go
func readFile(path string) error {
	f, err := os.Open(path)
	if err != nil {
		return err
	}
	defer f.Close() // 函数返回前执行，无论是否出错
	return nil
}
```

三条必须记住的规则：

1. **LIFO 后进先出**：多个 defer 按逆序执行
2. **参数在 defer 语句处立即求值**，函数体在返回时执行
3. **可以修改命名返回值**

```go
func demo() (cost int64) {
	start := time.Now()
	defer func() { cost = time.Since(start).Milliseconds() }()
	time.Sleep(10 * time.Millisecond)
	return 0
}
```

`defer` 不要放在循环里（除非循环次数很小），否则延迟调用会累积到函数返回才统一执行。

## 七、值传递：Go 只有值传递

Go 的函数参数永远是**值拷贝**：传 `User` 改不动原对象，传 `*User` 才能改。但 slice 和 map 的值是「描述符」（slice 含指针/长度/容量，map 是指向哈希表的指针），所以修改已有元素会影响原数据：

```go
func changeFirst(s []int) { s[0] = 100 }

func main() {
	s := []int{1, 2, 3}
	changeFirst(s)
	fmt.Println(s) // [100 2 3]
}
```

追加元素若触发扩容，新切片会指向新数组，与原切片分离。这正是 [06-切片-map-字符串](06-切片-map-字符串.md) 的重点。记住：**想让函数修改外部变量，传指针；想返回新数据，让函数返回它**。

## 常见坑

1. **`else` 换行导致编译错误**：`}` 与 `else` 必须同行，这是分号自动插入规则导致的。
2. **在 `range` 中修改元素副本**：`for _, u := range users { u.Name = "x" }` 不会生效，要用下标。
3. **循环里 `defer` 关闭资源**：文件句柄会累积到函数结束才释放，应抽成小函数或显式关闭。
4. **闭包捕获错觉**：Go 1.22 后每轮循环变量独立；但闭包共享外部变量时，改的仍是那个变量本身。
5. **误解 slice 传参**：`append` 返回的新切片必须赋值回去，否则等于白做。
6. **命名返回值 + 裸 `return` 滥用**：函数一长就难以追踪返回值，除短函数或配合 `defer` 外建议显式返回。

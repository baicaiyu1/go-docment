# 静态资源与文件上传

> 一句话定位：Hertz 用 `Static/StaticFS` 托管静态目录，用 `FormFile/MultipartForm` 接收上传，用 `File/FileAttachment` 返回文件；上传安全的关键是大小、后缀、文件名与存储路径四道校验。

## 本篇目标

- 掌握 `h.Static`、`h.StaticFile`、`h.StaticFS` 的用法与 `app.FS` 常用配置。
- 实现单文件、多文件上传，并正确设置请求体大小上限。
- 建立上传安全基线：后缀白名单、大小限制、随机文件名、防路径穿越。
- 会用 `c.File` 与 `c.FileAttachment` 实现预览与下载。
- 实现 SPA 的 history 路由回退，同时不吞掉 API 的 404。

## 前置知识

- 已完成 `03-基本特性/04-响应与渲染` 与 `03-基本特性/03-参数绑定与校验`。
- 了解 `multipart/form-data`、`os`、`path/filepath` 的基本用法。
- 知道相对路径依赖进程工作目录。

## 托管静态目录

准备目录结构：

```text
.
├── public
│   ├── index.html
│   ├── css/app.css
│   └── img/logo.png
├── uploads
└── main.go
```

### h.Static

```go
// 访问 /static/css/app.css → ./public/css/app.css
h.Static("/static", "./public")
```

`h.Static` 等价于把 `relativePath + "/*filepath"` 映射到本地目录，内部会做路径清洗与目录列表控制。

### h.StaticFile

```go
h.StaticFile("/favicon.ico", "./public/favicon.ico")
```

只暴露单个文件，适合 favicon、`robots.txt`、健康检查页。

### h.StaticFS

需要更细粒度控制时用 `StaticFS`：

```go
h.StaticFS("/assets", &app.FS{
	Root:               "./public",
	IndexNames:         []string{"index.html"},
	GenerateIndexPages: false,
	Compress:           true,
	AcceptByteRange:    true,
})
```

`app.FS` 常用字段：

| 字段 | 作用 |
| --- | --- |
| `Root` | 本地根目录 |
| `IndexNames` | 目录索引文件名，如 `index.html` |
| `GenerateIndexPages` | 无索引文件时是否生成目录列表，生产建议关闭 |
| `Compress` | 是否透明压缩（会尝试写缓存文件，需目录可写） |
| `AcceptByteRange` | 是否支持断点续传 |
| `PathRewrite` | 请求路径重写函数 |
| `PathNotFound` | 文件不存在时的兜底 handler |
| `CacheDuration` | 文件句柄缓存时间 |

## SPA 的 history 路由回退

前端使用 Vue Router / React Router 的 history 模式时，`/users/1` 这类路径在服务端没有对应文件，需要回退到 `index.html`：

```go
h.StaticFS("/", &app.FS{
	Root:       "./web/dist",
	IndexNames: []string{"index.html"},
	PathNotFound: func(ctx context.Context, c *app.RequestContext) {
		c.File("./web/dist/index.html")
	},
})
```

如果 API 与前端同域，建议先注册 API 路由，再用 `NoRoute` 做兜底，避免把 API 的 404 也回退成 HTML：

```go
h.NoRoute(func(ctx context.Context, c *app.RequestContext) {
	if strings.HasPrefix(string(c.Path()), "/api/") {
		c.JSON(consts.StatusNotFound, utils.H{"code": 404})
		return
	}
	c.File("./web/dist/index.html")
})
```

## 单文件上传

```go
func main() {
	_ = os.MkdirAll("./uploads", 0o755)

	h := server.Default(
		server.WithHostPorts("127.0.0.1:8080"),
		server.WithMaxRequestBodySize(20<<20), // 20MB
	)

	h.POST("/upload", func(ctx context.Context, c *app.RequestContext) {
		file, err := c.FormFile("file")
		if err != nil {
			c.AbortWithStatusJSON(consts.StatusBadRequest, utils.H{"message": "file is required"})
			return
		}
		if file.Size > 5<<20 {
			c.AbortWithStatusJSON(consts.StatusBadRequest, utils.H{"message": "file too large"})
			return
		}

		ext := strings.ToLower(filepath.Ext(file.Filename))
		if !allowedExt[ext] {
			c.AbortWithStatusJSON(consts.StatusBadRequest, utils.H{"message": "unsupported file type"})
			return
		}

		name := fmt.Sprintf("%d%s", time.Now().UnixNano(), ext)
		dst := filepath.Join("./uploads", name)
		if err := c.SaveUploadedFile(file, dst); err != nil {
			hlog.Errorf("save upload: %v", err)
			c.AbortWithStatusJSON(consts.StatusInternalServerError, utils.H{"message": "save failed"})
			return
		}
		c.JSON(consts.StatusOK, utils.H{"name": name, "size": file.Size})
	})

	h.Spin()
}
```

关键点：

- `c.FormFile("file")` 中的 `file` 是表单字段名，不是文件名。
- 临时文件在 handler 返回后会被清理，必须在 handler 内 `SaveUploadedFile` 或自行复制。
- 不要直接用 `file.Filename` 拼路径，它可能包含 `../`、绝对路径或非法字符。

## 多文件上传

```go
h.POST("/upload/batch", func(ctx context.Context, c *app.RequestContext) {
	form, err := c.MultipartForm()
	if err != nil {
		c.AbortWithStatusJSON(consts.StatusBadRequest, utils.H{"message": "invalid multipart form"})
		return
	}
	files := form.File["files"]
	if len(files) == 0 || len(files) > 5 {
		c.AbortWithStatusJSON(consts.StatusBadRequest, utils.H{"message": "1-5 files required"})
		return
	}

	names := make([]string, 0, len(files))
	for _, f := range files {
		if f.Size > 5<<20 {
			c.AbortWithStatusJSON(consts.StatusBadRequest, utils.H{"message": "file too large"})
			return
		}
		ext := strings.ToLower(filepath.Ext(f.Filename))
		if !allowedExt[ext] {
			c.AbortWithStatusJSON(consts.StatusBadRequest, utils.H{"message": "unsupported file type"})
			return
		}
		name := fmt.Sprintf("%d_%d%s", time.Now().UnixNano(), len(names), ext)
		if err := c.SaveUploadedFile(f, filepath.Join("./uploads", name)); err != nil {
			c.AbortWithStatusJSON(consts.StatusInternalServerError, utils.H{"message": "save failed"})
			return
		}
		names = append(names, name)
	}
	c.JSON(consts.StatusOK, utils.H{"names": names})
})
```

多文件字段名是 `files`，curl 需要重复传 `-F "files=@a.png"`。

## 大小限制的三层防线

1. **框架层**：`server.WithMaxRequestBodySize(20 << 20)`，超出直接 413，避免内存被打满。
2. **单文件层**：`file.Size > 5<<20`，防止用一个超大文件绕过业务限制。
3. **业务层**：文件数量、总大小、用户配额。

`MaxRequestBodySize` 统计的是整个请求体，包含 multipart 边界和其他表单字段，所以实际可用文件大小会略小于该值。上传接口不要沿用默认 4MB。

## 上传安全校验

| 风险 | 防线 |
| --- | --- |
| 超大文件打满磁盘/内存 | 请求体上限 + 单文件上限 + 数量上限 |
| 可执行脚本上传 | 后缀白名单，拒绝 `.php`、`.jsp`、`.sh` 等 |
| 伪装后缀 | 结合 `http.DetectContentType` 校验魔数 |
| 路径穿越 | 只用服务端生成的文件名，禁用用户文件名拼路径 |
| 覆盖已有文件 | 文件名加入时间戳/UUID，写入前检查是否存在 |
| 上传目录被直接执行 | 存储目录放在 Web 根目录之外，通过下载接口受控输出 |
| 权限过大 | 目录 `0755`、文件 `0644`，禁止 `0777` |
| 恶意 SVG/HTML | 下载时加 `Content-Disposition: attachment`，或单独域名托管 |

后缀白名单示例：

```go
var allowedExt = map[string]bool{
	".jpg": true, ".jpeg": true, ".png": true,
	".gif": true, ".webp": true, ".pdf": true,
}
```

路径安全示例：

```go
// 错误：用户可控
// dst := filepath.Join("./uploads", file.Filename)

// 正确：服务端生成
name := fmt.Sprintf("%d%s", time.Now().UnixNano(), ext)
dst := filepath.Join("./uploads", name)

// 如果必须使用原文件名做展示，先取 Base
displayName := filepath.Base(file.Filename)
```

## 文件下载

```go
h.GET("/files/:name/download", func(ctx context.Context, c *app.RequestContext) {
	name := filepath.Base(c.Param("name")) // 去掉任何目录部分
	path := filepath.Join("./uploads", name)

	if _, err := os.Stat(path); err != nil {
		c.AbortWithStatusJSON(consts.StatusNotFound, utils.H{"message": "file not found"})
		return
	}
	c.FileAttachment(path, name)
})

h.GET("/files/:name", func(ctx context.Context, c *app.RequestContext) {
	name := filepath.Base(c.Param("name"))
	c.File(filepath.Join("./uploads", name))
})
```

- `c.FileAttachment(path, filename)` 会设置 `Content-Disposition: attachment`，触发浏览器下载。
- `c.File(path)` 以内联方式返回，适合图片预览；对用户上传的 HTML/SVG 要谨慎，避免 XSS。
- `path` 必须是服务端可控路径；拿用户输入直接拼路径是路径穿越漏洞的根源。

## 完整可运行示例

```go
package main

import (
	"context"
	"fmt"
	"os"
	"path/filepath"
	"strings"
	"time"

	"github.com/cloudwego/hertz/pkg/app"
	"github.com/cloudwego/hertz/pkg/app/server"
	"github.com/cloudwego/hertz/pkg/common/hlog"
	"github.com/cloudwego/hertz/pkg/common/utils"
	"github.com/cloudwego/hertz/pkg/protocol/consts"
)

var allowedExt = map[string]bool{".jpg": true, ".jpeg": true, ".png": true, ".pdf": true}

func main() {
	_ = os.MkdirAll("./uploads", 0o755)
	_ = os.MkdirAll("./public", 0o755)

	h := server.Default(
		server.WithHostPorts("127.0.0.1:8080"),
		server.WithMaxRequestBodySize(20<<20),
	)

	h.Static("/static", "./public")
	h.StaticFile("/favicon.ico", "./public/favicon.ico")

	h.POST("/upload", func(ctx context.Context, c *app.RequestContext) {
		file, err := c.FormFile("file")
		if err != nil || file.Size > 5<<20 {
			c.AbortWithStatusJSON(consts.StatusBadRequest, utils.H{"message": "invalid file"})
			return
		}
		ext := strings.ToLower(filepath.Ext(file.Filename))
		if !allowedExt[ext] {
			c.AbortWithStatusJSON(consts.StatusBadRequest, utils.H{"message": "unsupported type"})
			return
		}
		name := fmt.Sprintf("%d%s", time.Now().UnixNano(), ext)
		if err := c.SaveUploadedFile(file, filepath.Join("./uploads", name)); err != nil {
			hlog.Errorf("save: %v", err)
			c.AbortWithStatusJSON(consts.StatusInternalServerError, utils.H{"message": "save failed"})
			return
		}
		c.JSON(consts.StatusOK, utils.H{"name": name, "size": file.Size})
	})

	h.GET("/files/:name", func(ctx context.Context, c *app.RequestContext) {
		name := filepath.Base(c.Param("name"))
		c.FileAttachment(filepath.Join("./uploads", name), name)
	})

	h.Spin()
}
```

## 常见坑

1. **静态路由写成 `h.Static("/", ...)`**：会匹配所有路径，把 API 路由也吞掉；静态资源用独立前缀，SPA 才用 `/` + 兜底。
2. **用 `file.Filename` 拼存储路径**：`../../etc/passwd` 可穿越目录；必须用服务端生成的文件名，展示时再 `filepath.Base`。
3. **只校验后缀不校验内容**：攻击者可上传伪装成 `.png` 的脚本；必要时用 `http.DetectContentType` 校验魔数。
4. **忘记调大 `WithMaxRequestBodySize`**：默认 4MB，稍微大一点的文件直接 413。
5. **handler 返回后才保存文件**：临时文件已被清理，异步保存会失败；必须在 handler 内完成复制。
6. **`SaveUploadedFile` 不会创建目录**：目标目录不存在会失败，启动时先 `os.MkdirAll`。
7. **把上传目录放在静态目录下**：用户可直接访问甚至执行上传文件；存储与托管分离，下载走受控接口。
8. **Windows 路径直接拼进 URL**：URL 永远用 `/`，本地路径用 `filepath.Join`。

## 小结

- 静态资源用 `Static/StaticFS`，SPA 用 `IndexNames` + `PathNotFound` 回退，但要保护 API 的 404。
- 上传用 `FormFile` / `MultipartForm`，在 handler 内完成保存。
- 安全靠四道校验：大小、后缀、服务端文件名、存储目录隔离。
- 下载用 `c.FileAttachment` 强制下载，`c.File` 用于受控的内联预览。

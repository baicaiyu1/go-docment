# 01-官方文档索引

> 一句话定位：把 Hertz、Kitex 与周边组件的官方文档按学习路径整理成导航，并标出对应的教程章节。

## 本篇目标

- 一页找到 Hertz 官方文档的概览、快速开始、开发指南、FAQ、参考与三方扩展。
- 拿到 Kitex、CloudWeGo、GORM、go-redis、Kafka、RocketMQ、Nacos、OpenTelemetry、Prometheus 的官方入口。
- 每条链接配一句说明并映射教程章节，避免“收藏了但不知道看哪篇”。

## 前置知识

- 已了解本教程的章节编号（`02-Hertz入门` 到 `15-附录`）。
- 能访问外网；公司网络下可先看仓库 README 与源码。

## 使用说明

- 链接以官方站点为准，版本更新后路径可能调整；打不开时先回到对应文档根目录。
- “对应章节”是阅读顺序建议，不是内容一一对应；同一篇官方文档可能被多章引用。

- 先读“快速开始”跑通，再用“基本特性”补细节，最后用“参考”查选项。
